# Firmware Manager — библиотека прошивок ECU

Веб-приложение для управления большой коллекцией прошивок блоков
управления двигателем (ECU). Поддерживает ВАЗ, Nissan, Toyota, BMW,
Renault, Hyundai, Kia, Ford, VW и др. Включает индексацию файлов
внутри архивов ZIP / RAR / 7Z / TAR, парсинг имён и текстовых
описаний, поиск и ручную сортировку «Неизвестных».

Оригиналы прошивок (`.bin`, `.hex` и архивы) **никогда не изменяются**:
архивы открываются только на чтение, извлечение — по одному файлу
в отдельную рабочую папку.

## Требования

- Python 3.10+
- Зависимости из `requirements.txt`
- Для **RAR**-архивов нужен внешний распаковщик в `PATH`:
  - Windows: `UnRAR.exe` (из WinRAR) или `bsdtar.exe` или `7z.exe`
  - Linux: `unrar` или `bsdtar`
- ZIP / 7Z / TAR работают без внешних утилит (через `py7zr`).

## Установка

```bash
cd D:\firmware_manager
python -m pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Откройте в браузере: <http://127.0.0.1:5000>

Параметры:

```bash
python app.py --root "D:\Firmware"          # сразу задать корень
python app.py --workspace "C:\FirmwareWork" # рабочая папка
python app.py --host 127.0.0.1 --port 8080 # адрес/порт
python app.py --scan                        # проиндексировать при старте
```

При первом запуске автоматически создаются:

- `firmware_index.db` — пустая SQLite-база;
- `passwords.json` — шаблон паролей.

## Рабочий процесс

1. В разделе **Поиск** → **Настройки индексации** укажите корневую папку
   с прошивками и архивами, нажмите **Переиндексировать**.
2. Дождитесь завершения (прогресс в консоли и на странице).
3. Ищите по строке (например `гранта м74 паулюс` или `M74.9`) и фильтрам.
   В полях поиска и фильтров работают подсказки: начните вводить `аз` —
   появятся `ВАЗ`, `ГАЗ`, `UAZ` и другие варианты; выбор подставляет
   точное значение. Для ЭБУ различаются `М74`, `М74.5`, `М74.9`,
   `М74М`, `М74.91` и `М74.9.1`.
4. **Копировать в workspace** — прошивка и связанный `.txt` копируются
   в рабочую папку.
5. **Неизвестные** — прошивки без марки/модели/ЭБУ, заполните поля
   и нажмите **Сохранить**.
6. **Рабочая папка** — список скопированных файлов, удаление, открытие.

## Пароли от архивов

Файл `passwords.json`:

```json
{
  "archives": {
    "vaz_2020.rar": "пароль",
    "D:/Firmware/BMW/msv70.7z": "bmw123",
    "*.zip": "default123"
  },
  "default_password": null,
  "notes": {
    "vaz_2020.rar": "пароль от Паулюса"
  }
}
```

Поиск пароля: полный путь → имя файла → частичное совпадение →
glob-маска → `default_password`. Пароли перебираются при чтении архива.

Если в имени архива есть подсказка (`... pass 4pda.rar`,
`... (pass 20tazOFF26).7z`, `... пароль 12345.zip`), приложение
попробует её автоматически, даже если архив не указан в `passwords.json`.

Перезапускать сервер после правки `passwords.json` не нужно: сохраните
файл и нажмите **Переиндексировать** (для уже проиндексированных
архивов пароль подхватывается и при копировании в рабочую папку).

## Безопасность оригиналов

- Архивы открываются только на чтение (`zipfile`, `rarfile`, `py7zr`).
- Массовая распаковка не выполняется. Из архива извлекается один файл
  только при копировании в workspace.
- Все операции записи — только в рабочую папку.
- `passwords.json` и база не содержат прошивок.

## Устранение неполадок

- **RAR не читается** — установите UnRAR / bsdtar / 7z и добавьте в `PATH`.
  Либо пересохраните архивы в ZIP.
- **Кракозябры в консоли** — запускайте из PowerShell с UTF-8:
  `chcp 65001` перед `python app.py`.
- **Большая база (>100k)** — индексация может занимать минуты;
  прогресс выводится в консоль.
- **Файлы не находятся** — проверьте, что расширения `.bin/.hex/.frf/.ori/.mod/.dat/.fls`.
  Другие расширения можно добавить в `archive_reader.FIRMWARE_EXTENSIONS`.
- **Запароленный архив не индексируется** — добавьте пароль в `passwords.json`
  и перезапустите индексацию.

## Лицензия

Оригиналы прошивок не модифицируются.
